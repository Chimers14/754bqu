MIXUP ARCHIVE - FIXED TEST BUNDLE

1. Make a backup of your current project folder.
2. Copy these updated project files into your project, replacing the matching files.
3. KEEP your existing sources/ folder and all its PNGs. They are not included in this download.
4. From the project folder in VS Code Terminal, run:
      python build_sources.py
      python -m http.server 8000
5. Open http://localhost:8000 and hard refresh (Ctrl+Shift+R).
6. Click a permanent book tab. Test FIT, +, -, 100%, page arrows and divider.
